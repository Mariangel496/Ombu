# Ombú – Tienda de mates online

Sitio web de una tienda ficticia de mates, yerbas y accesorios. Lo hice para la materia **Diseño y Desarrollo Web** de la Lic. en Gestión de Tecnología de la Información (UADE).

🔗 **Ver el sitio:** https://ombu-blond.vercel.app/

## Qué tiene

- Página principal con banner/carrusel automático
- Catálogo por categorías: mates, yerbas, canastas materas y más
- Página de detalle para cada producto
- Buscador de productos (con la lupa del header)
- Carrito de compras en un panel lateral, que se guarda con `localStorage`
- Contador de cantidad en cada producto
- Login visual con ventana modal
- Formulario de contacto

## Tecnologías

- HTML
- CSS
- JavaScript (sin frameworks)

## Cómo verlo en local

Descargá o cloná el repo y abrí `index.html` en el navegador. No necesita instalar nada.

## Estructura

```
index.html          → home
pag-*.html          → páginas de cada categoría
Mate*.html, Yerba-*.html, Canasta-*.html, Mas-*.html → detalle de productos
contacto.html / gracias.html
style.css           → estilos
script.js           → carrusel, buscador, login, contador y carrito
img/                → imágenes
```
